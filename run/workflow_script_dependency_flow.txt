Workflow Script Purposes
========================

- run/setup.py
  Creates or updates the global pathing JSON.

- run/generate_features.py
  Generates descriptor, fingerprint, and embedding feature CSVs.

- run/run_cfp.py
  Runs cross-feature prediction models.

- run/cfp_analysis.py
  Analyses cross-feature prediction outputs.

- run/run_single_prediction.py
  Runs single-property RF prediction models.

- run/pp_analysis.py
  Analyses single-property prediction outputs.

- run/feature_importance_analysis.py
  Averages RF feature importances across single-property prediction repeats and
  produces descriptor-group summaries for RDKit and Mordred.
